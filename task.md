# Frontend Task

These instructions apply only to the task named **Frontend Task**.

## Scope

- This is a frontend-only task.
- Do not inspect, modify, refactor, configure, test, or otherwise work on anything in the `backend` directory.
- Do not make backend API, server, database, migration, or authentication changes as part of this task.
- Keep all implementation changes inside the frontend scope unless the project owner explicitly changes this instruction.

## Colors and visual styling

- Follow the existing frontend color palette and design system.
- When the project owner provides specific colors, use those colors exactly.
- Do not introduce arbitrary new colors or replace existing palette colors without explicit approval.
- If a required color is not defined and has not been provided, pause that styling decision and ask the project owner for the color.
